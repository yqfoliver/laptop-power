# 笔记本电源自适应（LaptopPowerAuto）

一个 **零依赖、完全静默** 的 Windows 笔记本电源管理常驻程序。开机自启后缩在托盘里，根据 **插电/离电、前台程序、负载、温度** 自动切换电源策略，不弹窗、不打扰。

- 单文件 `笔记本电源自适应.exe`（约 8.6 MB），**不需要管理员权限、不需要装驱动**
- 面板形态：WebView2 网页面板（默认）/ 原生 GDI 窗口
- 13 套回归测试（380+ 项断言），全部离线或走假通道，不碰真硬件

---

## 下载与运行

1. 到 [Releases](../../releases) 下载 `笔记本电源自适应.exe`（或下载源码自行打包）。
2. 双击运行，托盘出现图标；右键可切档、开面板、退出。
3. 面板地址：<http://127.0.0.1:8753/>

> ⚠️ **首次运行若程序"没起来"**：未签名的 PyInstaller 单文件 exe 常被 Microsoft Defender 当成威胁直接删除（症状：开机无自启、日志一行都没有、exe 文件消失）。请把程序所在目录加入 Defender 排除项，再从原位置重新运行。

## 它能做什么

### 五档策略 + 自动判定

| 档位 | 场景 | 主要动作 |
|---|---|---|
| 游戏 | 前台是游戏 | 独显性能模式、功耗分配器把 CPU 瓦数让给 GPU |
| 办公 | Word / 浏览器 | 亮度 75%、待机与睡眠超时收紧 |
| 续航 | 离电日常 | 独显断电、降刷 60Hz、限 CPU 上限、亮度分级 |
| 极限省电 | 低电量 | 在续航基础上进一步压低上限 |
| 平衡 | 交还系统 | **切回系统自带「平衡」计划，不写一个字节** |

### 离电续航（实测口径）

本机实测：裸机 8.3~8.7 W → 续航档 6.2 W（约 −27%），60.2 Wh 电池对应 **7.1h → 9.7h**。

手段分五层，按收益从大到小：

1. **降刷 60Hz + 独显 ACPI 级断电**（GPU Eco）
2. **自建电源计划**里的处理器上限、待机/睡眠超时
3. 散热档位跟随
4. **PD 预算控制器**（见下）
5. 亮度分级（离电上限 45%）

### Type-C 弱电源保护（PD 预算控制器）

用 65~100 W 的 Type-C 线打游戏时，整机功耗可能超过线的供电能力，此时电池会被动放电"倒贴"。

控制器从电池充放电速率**实时学习这根线的可持续上限**（默认按 89 W 起步），并在逼近上限时逐级压制：先限 CPU 上限 → 再降亮度 → 最后降刷新率，**绝不让电池倒贴**。条件好转时按双门槛（绝对余量 25 W 与 62% 比例取严）逐级还原，避免在 60/165 Hz 之间反复抖动。

### 功耗分配器

插电游戏时，把 CPU 的瓦数让给独显：按实测功耗动态调 CPU 上限，知道什么时候该让、也知道什么时候该停（GPU 到达能效甜点后收手）。

### 面板

顶部判定当前前台程序，中间五个档位卡，下面是电池续航、散热风扇、功耗分配卡片与 Type-C 供电余量。

## 四条硬性底线

这不是设计偏好，是每次技术选型的裁决依据：

1. **完全静默** —— 不弹窗、不黑窗、不气泡。所有失败只写日志（`boot.log` / `exit.log`）。
2. **零依赖、普通权限** —— 不要管理员、不装驱动。这条直接否决了 SMU 直写 TDP（需要内核驱动）。
3. **不改系统自带计划** —— 系统「平衡」计划一个字节都不动，只用自建计划 `笔记本自适应电源`。
4. **实证优先** —— 文档口径、软件界面、他人数据都只是线索，一切以本机实测为准。

## 适用机型

本项目在**华硕（ATKACPI）机型**上开发：可读温度/功耗/风扇档/TGP，可靠写入「GPU Eco 独显断电」。

其它品牌（联想、惠普、戴尔、机械革命等）**大概率不能直接复用厂商接口**，但核心思路通用。参见：

- [`用WorkBuddy复刻到其它品牌.md`](用WorkBuddy复刻到其它品牌.md) —— 各品牌接口矩阵 + 三段式提示词写法
- [`项目经验总结.md`](项目经验总结.md) —— 完整踩坑记录与实测数据

即使厂商接口完全不可用，以下部分仍然有效：自建电源计划、处理器上限、刷新率、亮度、待机超时、PD 预算控制器。

## 开机自启

程序默认写注册表 Run 键（直启 exe，不经任何脚本）。若被安全软件拦截，可改用计划任务：

```cmd
schtasks /create /tn "LaptopPowerAuto" /xml "LaptopPowerAuto-task.xml" /f
```

（需在**非沙箱的系统终端**执行；登录触发 + 延迟 15 秒。）

导入前先把 `LaptopPowerAuto-task.xml` 里两处 `<你的用户名>` 换成你自己的路径。

## 已知边界

- **ATKACPI 写入基本被固件拒绝**（性能模式 / 风扇曲线 / 充电阈值 / PPT 写后回读会还原），只有 GPU Eco 可靠。这不是本程序的限制，是厂商固件行为。
- **SMU 直写 TDP 未采用** —— 需要内核驱动 + 管理员，违背零依赖底线。替代方案是实测功耗 → 动态调处理器上限的用户态闭环。
- 显卡功耗计偶发坏值（如 500 W+），PDH 与 NVML 读数都做了清洗与交叉校验。

## 目录结构

```

  manager.py   档位判定 + 巡检循环 + 限频自愈看门狗

  alloc.py     插电游戏功耗分配器
```
